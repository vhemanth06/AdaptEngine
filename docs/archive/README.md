# Archive

This folder holds the project's history: weekly submissions, working notes, superseded
specifications, old pre-registrations and old figures. It is read-only. Each Markdown file starts
with a one-line banner; nothing else in it was changed when it was archived on 21 Nov 2026, so its
paths, commands and numbers describe the repository as it was then. Current documentation starts at
[docs/README.md](../README.md).
